Flow 1: Structure Map (archaeologist.py project --src <roots>)

Extracts classes, interfaces, React components, and module functions into a reference graph.

1
Dispatch: archaeologist.py → build_wiki.py
run_project() invokes build_wiki.build(src, vault_dir) with verified source directories.
2
Multi-Language Extraction
build_wiki.py runs px.iter_py_files(), js_ts_extract.find_js_files(), and langs_extract.find_lang_files(). Tree-sitter parsers produce CST trees.
3
ID Disambiguation & Layer Inference
core/ids.py:SharedNames groups names by lowercase to qualify collisions across files. core/taxonomy.py:infer_layer() assigns layers. Notes written to data/structure/vault/*.md.
4
Graph Assembly: build_graph.py
build_graph.build() parses wikilinks [[Target]] and frontmatter metadata from the vault, emitting deterministic graph.json and registry.json.
5
Explorer Bundling & Manifest Write
build_html.build() inlines the graph into data/explorer.html. manifest.write(src) records SHA-256 hashes into manifest.json.

Flow 2: Flow Map (archaeologist.py flow --src <roots>)

Extracts method/function nodes, resolves calls against declared types, tracks dropped calls, and builds execution paths.

1
Pass 1: Registration
build_flow.py extracts all function/method definitions across Python, JS/TS, and 15 languages, registering them into core/ids.py:SharedNames.
2
External Route Table Ingestion
route_tables.find_route_tables() extracts route endpoints from Django urlpatterns, Rails routes.rb, Laravel, and Phoenix, attaching them to controller handler nodes.
3
Pass 2: Two-Pass Call Resolution
Resolves calls via local typed assignments, parameter annotations, and langs_extract._pick_overload(). Connects frontend fetch/axios calls to backend routes.
4
Dropped Call Tracking (unresolved)
_record_dropped() and _split_dropped() classify dropped calls: calls naming known in-graph nodes are logged in unresolved as investigation clues, avoiding guessing false edges.
5
Graph Output & HTML Bundling
Writes data/flow/notes/*.md and data/flow/flow_graph.json. Re-renders data/explorer.html and updates manifest.json.

Flow 3: Dual Map Build (archaeologist.py both --src <roots>)

Runs Flow 1 (Structure) followed immediately by Flow 2 (Flow), then writes the unified manifest.

1
Run Flow 1: Structure Map
Generates data/structure/graph.json and vault/*.md.
2
Run Flow 2: Flow Map
Generates data/flow/flow_graph.json and notes/*.md.
3
Unified Offline Explorer & Manifest
build_html.py bundles both maps into data/explorer.html with a switch header. manifest.write() seals source hashes.

Flow 4: Architecture Review & Health Audit (archaeologist.py report --src <roots>)

Executes 7 deterministic review passes and generates an executive architecture report.

1
Dispatcher Loop: report.build() per map
archaeologist.py:run_report() runs report.build() for each built map (structure, flow).
2
Security & Git Churn Scans
scan_security.scan() maps regex findings to AST node ranges via owner_of(). git_insights.build() streams git log --numstat to rank hotspots.
3
Tarjan's SCC & Health Scoring
analyze.report() detects circular dependencies via iterative Tarjan's SCC, checks layer violations, and computes an A–F health grade.
4
Metrics, Debt, Tests & Duplicates
metrics.build() measures cyclomatic complexity; debt.build() catalogs TODO markers; tests_map.build() maps test coverage; duplicates.build() winnows copied blocks ($K=10, W=21$).
5
Report Assembly & Embedding
Emits architecture_report.md and .json. Calls build_html.build() to inline reports into data/explorer.html.

Flow 5: Staleness Check (archaeologist.py check [--src <roots>])

Deterministic source-freshness check; verifies if working tree files or grammar wheels have changed since the last build.

1
Call: manifest.compare(src)
Reads recorded source roots and grammar versions from data/cache/manifest.json.
2
SHA-256 Hash Comparison & Grammar Drift
Re-scans roots, hashes current files, and checks core/grammars.py:drift(). Emits a JSON summary of modified/added/deleted files. Zero graph re-parsing needed.

Flow 6: Orientation Brief (archaeologist.py brief)

Instant orientation digest for agents or developers; constant-time execution reading pre-computed JSON files.

1
Dispatch: brief.main()
Directly loads manifest.json, graph.json, and architecture_report.json.
2
Token Digest Output
Formats node/edge counts, health grade, top hotspots, entry points, and high-severity risks into a fixed-token text summary.

Flow 7: Agent Zero-RAG Retrieval & Query Flows

High-speed BFS path tracing, blast radius impact calculation, and token-budgeted context packing.

1
Path Tracing & Blast Radius: trace_path.py
Forward BFS finds shortest call paths between nodes. Reverse BFS on incoming edges calculates upstream blast radius for modified nodes or git diff changes.
2
Context Budget Packing: context.py
Gathers node facts, neighbors, security findings, and precision notes; dynamically contracts neighbors using NEIGHBOR_CAPS = (12, 6, 3, 1) to fit within --max-chars.
3
Multi-Filter Search: search.py
Filters graph nodes by name, docstring, layer, route, fan-in/fan-out, or complexity without grepping raw source files.
Operational Scenarios

How the System is Used in Practice

Scenario 1: Codebase Ingestion & Graph Building

The engine scans target source directories, parses every file via Tree-sitter, disambiguates names, resolves calls down to declared types, and writes deterministic JSON graphs and Markdown notes.

# 1. Build both maps from source python .agents/skills/code-archaeologist/scripts/archaeologist.py both --src ./sample_src

Artifacts Produced:
• data/structure/graph.json & vault/*.md (25 nodes, 22 edges)
• data/flow/flow_graph.json & notes/*.md (53 nodes, 33 edges, 16 endpoints)
• data/explorer.html (Self-contained viewer embedding both graphs and vendored force-graph)

Scenario 2: Zero-RAG Architecture Query & Impact Analysis

An AI agent or engineer asks questions about call paths, blast radius, or component neighbors. Instead of loading 100,000 tokens of raw source code, the agent queries the graph using BFS and reads only the returned notes (~1,500 tokens).

# Trace execution path from frontend handler to repository python .agents/skills/code-archaeologist/scripts/query/trace_path.py \ --graph .agents/skills/code-archaeologist/data/flow/flow_graph.json \ --from submitOrder --to OrderRepository.save # Blast radius: what breaks if OrderRepository.save changes? python .agents/skills/code-archaeologist/scripts/query/trace_path.py \ --graph .agents/skills/code-archaeologist/data/flow/flow_graph.json \ --impact-of OrderRepository.save

Output: Returns submitOrder > createOrder > OrderController.create_order > OrderService.place_order > OrderRepository.save followed by reading only those 5 note files.

Scenario 3: Code Health, Smells & Duplicate Audit

Runs 7 analysis passes: Tarjan's SCC cycle detection, Winnowed code clones, regex vulnerability mapping, git churn hotspots, and McCabe complexity metrics, outputting an executive brief and unified report.

# Generate unified architecture report python .agents/skills/code-archaeologist/scripts/archaeologist.py report --src ./sample_src # Read instant orientation brief (fixed-size digest) python .agents/skills/code-archaeologist/scripts/archaeologist.py brief

Results: Computes an A-F health grade, spots copy-pasted blocks ($K=10, W=21$), locates cycles, and attributes security findings to exact AST node ranges.
