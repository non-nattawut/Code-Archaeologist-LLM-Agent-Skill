สำรวจ graph การเรียกระหว่าง script อย่างละเอียด Code Archaeologist ประกอบด้วย 29 script ที่แต่ละตัวทำงานเฉพาะทาง และคุยกันผ่าน contract ที่ deterministic, taxonomy ที่ใช้ร่วมกัน และ artifact บน filesystem

ทั้งระบบ ใน Flowchart เดียว (คลิกกล่อง script ใดก็ได้เพื่อดูกลไกของมัน หรือคลิก chip ของคำสั่งเพื่อดูลำดับ script ที่มันรันจริง — ทั้งหมดอยู่ใน sidebar ไม่ต้องเลื่อนหน้าเลย)
สอง phase กับหนึ่งบานพับที่คั่นกลาง
